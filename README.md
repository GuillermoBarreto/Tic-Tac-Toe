# Tic-Tac-Toe

Classic Tic-Tac-Toe game in Java, played in the console.

## Tech stack

- Java (no dependencies)

## How to run

```bash
javac TicTacToe.java
java TicTacToe
```
## How to play

Two players alternate entering a cell number (1-9). First to line up three
marks wins; a full board with no winner is a draw.

```
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9

Player X, enter a number (1-9):
```
